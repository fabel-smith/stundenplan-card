# Kalenderbeispiel

[Einrichtung und Verwendung](../../docs/CALENDAR.md)

`schultermine.yaml` ist ein Home-Assistant-Package. Es liest einen Kalender
und stellt Termine fuer die zusaetzliche Sensorquelle der Stundenplan Card bereit.
Die Datei ist keine Kartenkonfiguration und gehoert nicht in `automations.yaml`.

Die weiteren Dateien dienen nur der lokalen Pruefung durch Entwickler.
Fuer die Einrichtung in HA werden sie nicht benoetigt.
