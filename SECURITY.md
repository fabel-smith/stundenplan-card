# Security reports

Please do not publish passwords, tokens, real school schedules, children's data,
or an exploit containing private data in an issue or pull request.

Use [GitHub's private vulnerability reporting](https://github.com/fabel-smith/stundenplan-card/security/advisories/new)
for suspected security vulnerabilities. If this option is unavailable, open an
issue containing only a request for a private contact method, with no sensitive
details. Regular display bugs can be reported in public using fictional data.

Include the affected version, a minimal fictional example and reproduction steps.
Review logs and screenshots for personal data before sharing them, even privately.
Please test with the latest release. There is no guaranteed response time or
ongoing security maintenance commitment for old releases.
